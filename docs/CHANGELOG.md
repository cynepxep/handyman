## Этап 1 — доработки по замечаниям владельца (2026-09-24, вечер)

- **Плитки на главной кликабельные**: «товаров», «есть у поставщика», «Под заказ», «расхождений цен», новая «нужно разложить по категориям» —
  открывают список товаров с нужным фильтром.
- **Закупочная цена** (`Product.purchasePrice`, миграция `purchase_price`): поле рядом с РРЦ в карточке товара, вводится вручную (способ
  автоматического расчёта владелец пока не определил: «нужна возможность»). Показывается «с одной штуки вы зарабатываете X ₴ (Y%)» и

- **Фото на весь экран** в карточке: клик по миниатюре, листание стрелками и кнопками, Esc закрывает.
- **«Нераспределённые»**: товары без категории в фиде больше не пропускаются, а попадают в системную категорию `unsorted`
  (не видна покупателям и не попадает в поиск). В списке товаров — отметка галочками и «Перенести в категорию» (категория защищается от импорта).
  Когда у такого товара появится категория в фиде, он переедет сам (если вы его не переносили вручную).
- **Страница категорий**: подписаны колонки (название укр./рус., «Порядок в меню» с объяснением), понятные счётчики
  («всего N, прямо в этой M, в подкатегориях K»), плашка «Нужно разложить по категориям».
- Тесты: 65 (добавлены закупочная цена, массовый перенос, «Нераспределённые» при импорте, исключение из поиска).
- Проверено вживую на реальной базе: импорт (+2 «Нераспределённых», 1 обновление, 2 ушли из фида в архив), плитки-ссылки, список нераспределённых,

## Этап 1 — Каталог (завершён 2026-09-24)

Правила и допущения подробно: `docs/CATALOG-IMPORT.md`.

Сделано:
- **Импорт XML-фида Vitals** (`/admin/import`): проверка без записи → выбор категорий → применение в фоне с полосой прогресса →
  журнал запусков. Источник: ссылка (по умолчанию ссылка Vitals) или загруженный файл. Разбор через `fast-xml-parser`
  (единственная новая зависимость), кодировка читается как UTF-8, лимиты сущностей обойдены собственным декодером.
- **Правила из старого проекта**: обновление по артикулу, ручные правки защищены (`ProductFieldLock`), пустые значения не затирают,
  заблокированная цена → «расхождение», каждое изменение цены в `PriceLog`. **Новое**: скачок цены >30% ждёт подтверждения,
  пропавшие из фида товары остаются как «Под заказ», отчёт об ошибках по строкам, применяется ровно то, что показали при проверке.
- **Цена = РРЦ** (цена фида Vitals), наценка 0%: решение владельца. Механизм наценки поставщика сохранён на будущее.
- **Категории**: автоподсказка по названиям (украинские, адаптирована из старого `autoCategory`), решения владельца запоминаются
  (`FeedCategoryMap`, действует самый длинный путь), подкатегории (до 2 уровней) создаются автоматически из дерева фида.
  Страница `/admin/categories`: дерево с числом товаров, правка названий и порядка.
- **Товары** (`/admin/products`): список с поиском и фильтрами (наличие, расхождение цен, ручные правки, скрытые, пропавшие из фида),
  карточка с правкой, автоматической защитой изменённых полей, снятием защиты, «принять цену поставщика», историей цен,
  фото и характеристиками. Описания очищаются от опасного HTML.
- **Поиск Meilisearch** + публичный API `GET /api/catalog/search` и `/api/catalog/suggest` (для витрины Этапа 2): опечатки, артикул
  (и без нулей), исправление раскладки («rheu» → «круг»), стартовые синонимы, «в наличии» выше «под заказ», фильтры со счётчиками
  (диаметр, хвостовик, материал, напряжение, мощность, серия и др.), бренд, цена, скидка, сортировки.
  Индекс обновляется после импорта, правки товара и категории; `pnpm search:reindex` и кнопка на главной админки — ручная пересборка.
- **Админка**: общий каркас с меню и адаптивной вёрсткой (админка `(panel)`), главная со статистикой каталога и состоянием поиска.
- Новые миграции: `20260924144357_catalog_import`, `20260924145745_attribute_sort` (только добавления, см. `MIGRATION-NOTES.md`).
- **Тесты** (их не было): `pnpm test` — 61 проверка (`node:test` + `tsx`, без новых зависимостей): разбор фида, категории, планировщик
  импорта, синонимы/раскладка/фильтры (39, без Docker); интеграционные на отдельной базе `handyman_test` и индексе `products_test` (22).
