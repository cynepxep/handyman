# 03. Требования к дизайн-системе

Источник: ТЗ (разделы «Дизайн-система», «Мобильный UX», «Скорость», «Доступность», «Мелочи профессиональной вёрстки»). Пункты **«допущение»** выведены нами, владелец их ещё не подтвердил.

## UI-kit в Figma (или другом инструменте)

Все элементы — **переиспользуемые компоненты**: цвета, шрифты, отступы, кнопки, поля, карточки, бейджи, модальные окна. Макеты страниц собираются только из компонентов kit'а.

Минимальный набор компонентов (**допущение** — выведен из перечня экранов):

| Группа | Компоненты |
|---|---|
| Основа | цвета (фон, поверхность, текст, приглушённый текст, линия, акцент, успех, ошибка, предупреждение), типографика, сетка, отступы, радиусы, тени, иконки |
| Кнопки и ссылки | основная, вторичная, текстовая, иконка-кнопка, «В корзину» со счётчиком ±, липкая кнопка на телефоне, экспресс-оплата (Apple Pay / Google Pay), состояния: обычная, hover, нажата, фокус, отключена, загрузка |
| Поля | текст, телефон (маска +380), поиск с подсказками, выпадающий список, автозаполнение города/отделения, флажок, переключатель, радио, ползунок цены, количество ±, ошибка/подсказка |
| Товар | карточка в списке (вертикальная/горизонтальная), карточка-мини (в подсказках, корзине), бейджи (скидка, «В наявності», «Під замовлення», «Хіт», «Новинка»), цена (текущая/старая/за упаковку/опт), рейтинг |
| Каталог | плитка категории, чип фильтра, группа фильтра (сворачиваемая, со счётчиками), шторка фильтров (телефон), сортировка, пагинация, скелетон |
| Навигация | шапка (обычная и уменьшенная), меню каталога, нижняя панель (телефон), хлебные крошки, переключатель языка |
| Оверлеи | модальное окно, шторка снизу, боковая мини-корзина, тост, cookie-баннер, полноэкранный поиск, полноэкранная галерея |
| Контент | заголовки, богатый текст (заголовки/списки/таблицы/ссылки), таблица характеристик, аккордеон, блок доверия, отзыв |
| Состояния | пусто, загрузка, ошибка, нет сети, 404 |

## Токены (в коде — CSS-переменные)

Значения в Figma **и** в коде совпадают: поменял цвет в одном месте — поменялся везде, включая Mini App. Дизайнер передаёт токены таблицей или через переменные Figma (Variables). Именование — по смыслу, а не по цвету (`--color-accent`, а не `--color-yellow`).

Отправная точка из рабочего прототипа (**только референс**): фон `#F2F2EE`, карточка `#FFFFFF`, текст `#1E2126`, приглушённый `#6B7078`, линия `#E1E1DB`, акцент `#FFC61A`, успех `#1F9D55`, ошибка `#D6453D`, радиус 14 px; тёмная тема (фон `#16181C`, карточка `#21242A`, текст `#F1F1EC`).

## Типографика

- **Полная поддержка украинского и кириллицы**: обязательно есть **ґ, є, і, ї**.
- **Свой хостинг шрифта**, вариативный формат (быстрее, без внешних запросов).
- Учесть, что русский текст на 15–20 % длиннее украинского (проверять макеты на длинных подписях).
- Шкала размеров для телефона и десктопа; минимальный размер основного текста на телефоне (**допущение**: не меньше 16 px, чтобы iOS не увеличивал поле ввода).

## Сетка и брейкпоинты

**360, 768, 1280, 1440 px.** Отступы и колонки — по сетке, поля от края на телефоне единые.

## Мобильный UX (главные требования ТЗ)

- Нижняя панель навигации: Каталог, Поиск, Корзина, Кабинет.
- Фильтры открываются **снизу шторкой**, кнопка «Показати 48 товарів» **закреплена** внизу.
- Поиск открывается на весь экран с историей и популярными запросами.
- Мини-корзина выезжает сбоку.
- Кнопки и зоны нажатия **≥ 44 px**, главные действия в зоне большого пальца.
- Маски ввода телефона (+380), цифровая клавиатура для номеров, автозаполнение адреса.
- Экспресс-кнопки Apple Pay / Google Pay в карточке и корзине.
- Липкая кнопка «В корзину» на карточке (телефон).

## Скорость (цели ТЗ, на телефоне)

| Метрика | Цель |
|---|---|
| LCP (загрузка главного контента) | до 2,5 с |
| INP (отклик на нажатие) | до 200 мс |
| CLS (прыжки вёрстки) | до 0,1 |
| Вес страницы каталога | до 1,5 МБ |

Как достигаем — влияет на дизайн: изображения AVIF/WebP с адаптивными размерами, ленивая загрузка, **скелетоны вместо пустоты**, предзагрузка страницы при наведении, минимум сторонних скриптов (пиксели только через GTM), проверка Lighthouse при каждом обновлении. **Дизайн должен заранее резервировать место под картинки** (фиксированные пропорции), чтобы не было прыжков.

> Важно: фото товаров сейчас — ссылки на сайт Vitals, 1000×1000 px, около 300 КБ каждое. Для цели «до 1,5 МБ» их придётся уменьшать (см. `06-OPEN-QUESTIONS.md`, вопрос Т1). Пропорция фото товара — **квадрат 1:1** (все фото Vitals квадратные — **допущение**, проверить на выборке).

## Доступность (WCAG 2.2 AA)

- Контраст текста **не ниже 4,5:1** (проверять и для тёмной темы, и для акцентного цвета на кнопках).
- **Видимый фокус**, работа с клавиатуры.
- Подписи для иконок и полей; alt-тексты фото (генерируются из названия и характеристик).
- Это же помогает SEO.

## Мелочи профессиональной вёрстки (ТЗ)

Липкая шапка, которая уменьшается при прокрутке; кнопка «Наверх»; «Показать ещё» + нумерация; сохранение позиции прокрутки; красивые превью в Telegram/Viber; продуманные состояния (загрузка, ошибка, пусто, нет в наличии, нет сети); data-атрибуты для GTM.

## Передача в разработку

1. Токены (цвета, размеры, шрифты, радиусы, тени, отступы) — таблицей/переменными Figma → в код как CSS-переменные.
2. Компоненты kit'а → компоненты Next.js (`apps/web`), по одному на компонент, с теми же названиями.
3. Иконки — SVG (набор или библиотека, лицензия должна разрешать коммерческое использование).
4. Шрифты — файлы с лицензией на веб-использование (самохостинг).
5. Макеты Open Graph-превью, favicon, иконки для установки на экран телефона (PWA, позже).
