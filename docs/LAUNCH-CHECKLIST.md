# Чек-лист запуска (шаг 8.5)

Проходится **на сервере с настоящим доменом** после переезда (`docs/LAUNCH.md`, раздел 6) и **до** кнопки «Открыть сайт для Google».
Отмечайте галочки прямо в файле (`[ ]` → `[x]`) или распечатайте. Что не получилось — строку с ошибкой и снимок экрана показать Claude.
Закрывает хвосты Х4, Х8, Х13 (оплата и чеки) из `docs/PLAN-TO-LAUNCH.md`.

**Два вида заказов**:
- **тестовый** — оформлен, пока вы вошли в админку в этом же браузере: помечен «🧪 ТЕСТ», не считается в отчётах, **сам не уходит в KeyCRM**;
- **настоящий** — из браузера **без входа в админку** (окно «инкогнито» или телефон, где админка не открыта): так проверяется то, что увидит покупатель,
  и передача в KeyCRM. После проверки такой заказ **отменить** (причина — «тест») и в KeyCRM тоже.

Для проверок удобно положить в корзину один недорогой товар, который есть **на нашем складе** (видно остаток — так проверяется и склад).

## 1. Перед началом

- [ ] «Настройки → Проверка перед запуском» — всё «готово», кроме «Сайт открыт для Google»
- [ ] «Интеграции» — у каждого подключённого сервиса «Проверить подключение» зелёное
- [ ] «Резервные копии» — есть копия за сегодня, проверка восстановления зелёная
- [ ] сторож UptimeRobot показывает «Up» (`docs/LAUNCH.md`, раздел 8)
- [ ] «Уведомления» — галочки «Заказы» и «Тревоги» включены, чат менеджеров указан
- [ ] у владельца включён код из приложения («Мой аккаунт»)

## 3. Оплата и чеки (если оплата картой включена)

- [ ] В «Сайт → Оформление заказа» временно поставить предоплату **10 ₴** (запомнить прежнюю сумму)
- [ ] Настоящий заказ → на странице «Дякуємо» **«Сплатити»** → оплатить своей картой
- [ ] Заказ сам стал «Оплачен» (без обновления страницы — через уведомление mono); в заказе блок «Оплата картой» — оплачено 10 ₴
- [ ] В заказе блок «Кассовые чеки» — чек продажи; ссылка на чек на странице заказа открывает чек (`check.checkbox.ua/…`)
- [ ] «Вернуть деньги» (право «Оплата: возврат денег покупателю») → деньги пришли на карту; чек возврата создан
- [ ] Вечером (после 23:00) — смена в Checkbox закрылась сама
- [ ] Вернуть прежнюю сумму предоплаты

## 4. Telegram: бот, вход и Mini App

- [ ] Боту `/start` → выбор языка → кнопка **«Магазин»** открывает сайт внутри Telegram
- [ ] «Поделиться номером» в боте → в «Клиентах» у клиента с этим номером появился Telegram
- [ ] Кнопка меню Mini App (слева от поля ввода, настраивается в @BotFather) открывает сайт внутри Telegram; вход — сам, без пароля
- [ ] В Mini App положить товар в корзину → на сайте в браузере (после входа через Telegram) — та же корзина
- [ ] На товаре **«Повідомити про зниження ціни / надходження»** → нажать → бот прислал подтверждение (Х4)
- [ ] Вопрос к товару (вошли через Telegram) → ответить в «Отзывы» → автор получил ответ в Telegram (Х4)
- [ ] Вход на сайт через Telegram (если кабинет включён, Х8): код → бот → сайт открылся уже вошедшим
