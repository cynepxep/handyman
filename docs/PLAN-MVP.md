# План: минимальный запуск сайта (черновик, обсуждаем с владельцем)

Решение владельца 2026-09-28: сначала запускаем **маленький сайт, который гладко работает у покупателя**, и минимальную админку для продаж.
Всё остальное из старого плана (`PLAN-TO-LAUNCH.md`) — в блоке «Дальше»: **выключено, но не удалено**, включаем по одному на работающем сайте.

**Статус: черновик.** Код — только после «да» владельца. Работать по нему — в новой сессии, по шагам М1, М2… сверху вниз.

## Правила работы (чтобы «одно чиним — другое не ломалось»)
1. Шаги делаются подряд, без остановок; от владельца на каждом шаге ничего не нужно. Результат владелец смотрит, когда готова пачка шагов.
2. Перед слиянием в `main` — автотест **основного пути** в браузере (телефон и компьютер): найти товар → карточка → корзина →
   оформление с Новой Почтой → заказ появился в админке (и в KeyCRM). Не прошёл — в `main` не попадает.
3. Выключенное не удаляем: прячем переключателем. Включение каждой функции из «Дальше» — отдельный шаг с той же проверкой.
4. Новых функций до запуска не добавляем, кроме шагов этого плана.

## Что уже есть и должно просто гладко работать
**Покупатель**: главная, каталог с фильтрами, поиск, карточка товара с фото, корзина, оформление (имя, телефон, город и отделение НП,
способ оплаты), страница «Дякуємо» с номером заказа, «Контакти», «Доставка і оплата». Язык — украинский (русская версия — в «Дальше»).
**Админка**: импорт товаров (поставщики, бренды, отмена загрузки), товары (цена, название, скрыть, «Хит»/«Новинка»), фото товаров,
меню каталога, заказы (список, карточка, статусы, печать), «Сайт» (тексты, контакты, график, главная, оформление заказа),
«Интеграции» (ключи), сотрудники, сообщение о новом заказе в Telegram.

### М2 — свой склад: правила (предложение)
- Галочка «Є в магазині» включена, количество пустое → на сайте «В наявності в магазині», при заказе ничего не уменьшается; снимаете галочку сами.
- Указано количество → на сайте «В наявності в магазині» (число покупателю не показываем), при заказе количество уменьшается;
  дошло до 0 → галочка снимается сама, товар показывается как «у постачальника, 3–4 дні» или «під замовлення» (как по фиду).
- Один склад — магазин в Одессе. Несколько точек, приход, инвентаризация, журнал — в «Дальше».

актуальные редакции законов проверяются при составлении; перед публикацией желательно показать юристу или бухгалтеру.
