# Проверка в браузере

## Вход в админку — без ввода пароля
Пароль `owner` неизвестен и не нужен.
1. Скрипт (из `packages/db`, `pnpm exec dotenv -e ../../.env -- tsx <файл>`) создаёт **временную** учётную запись: `hashPassword` из core,
   роль `owner`, логин `claude-test`, и строку `StaffSession`.
2. Cookie ставит временный адрес `app/api/tmp-claude-login/route.ts` (только не в production; `document.cookie` в браузерной панели не работает).
   На рабочей сборке (`next start -p 3200`) временный вход включается `HM_TMP_LOGIN=1`.
3. После проверки удалить: адрес `tmp-claude-login`, скрипт, сессию и учётную запись (`Staff`, `StaffSession`; учётка `claude-test` при удалении
   чистит и свои записи в `AuditLog`), тестовые заказы/клиентов/Outbox, и сбросить счётчик номеров заказов:
   `SELECT setval(pg_get_serial_sequence('"Order"', 'seq'), 1, false)`. Удали и другие тестовые данные (например, `ImportRun` со статусом
   `PREVIEW`), верни тестовые правки товаров.

## Браузерная панель Claude
- Панель может быть 0×0 (дерево доступности пустое) — работай через `javascript_tool` (`form.requestSubmit()`, чтение `innerText`).
- Панель часто **скрыта** (`document.visibilityState === "hidden"`): не срабатывают `requestAnimationFrame` и события фокуса, React не показывает
  догружаемые блоки (`loading.tsx` остаётся на экране, настоящее содержимое лежит в `div[hidden]`). Это не ошибка сайта: проверяй содержимое скриптом.
- Скриншоты иногда не получаются («page did not finish rendering» или белый кадр): окно за другими, а не ошибка страницы. Проверяй скриптом
  (`getComputedStyle`, `getBoundingClientRect`, `innerText`).

## Тесты в браузере (Playwright)
- `pnpm test:e2e` — 13 сценариев витрины на телефоне 412 px; сайт на :3100 должен работать (или запустится сам). Заказы тесты не создают.
- На компьютере владельца — установленный Google Chrome. В облачном чате Claude — Chromium контейнера (`E2E_CHROME_PATH`, задаёт
  `.claude/hooks/session-start.sh`). В облаке каталог пробный (19 товаров из образца фида), поэтому проходят только сценарии без
  конкретных товаров (поиск, русская версия, 404, кабинет — 4 из 13); остальные требуют настоящий каталог.

## Lighthouse
Только на рабочей сборке: `pnpm build`, затем в `apps/web`: `npx dotenv -e ../../.env -- npx next start -p 3200`,
`npx -y lighthouse@12 http://localhost:3200/ --chrome-flags="--headless=new"` (путь к Chrome — `CHROME_PATH`). Баллы на ПК владельца «плавают» ±8,
первая раскладка медленная из-за шрифтов Windows — сравнивай с эталонной пустой страницей, а не с идеалом.
